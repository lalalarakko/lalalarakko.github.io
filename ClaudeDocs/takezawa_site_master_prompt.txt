## 0. 【最重要】作業の絶対ルール

### mdファイルについて
- **Claudeはmdファイルをスクラッチから生成しない**
- **先生が管理するmdファイルを丸ごと上書きしない**
- **先生から明示的に指示されていないmdファイルを変更しない**
- **JSONに存在しないデータをmdに書き込まない（ハルシネーション厳禁）**

### astroファイル・cssについて
- Claudeが担当するのは `.astro` ファイルと `global.css` のみ
- 修正依頼時は必ず現在のファイルをアップロードしてもらい、そのファイルを修正して返す
- スクラッチから書き直さない

### publications更新の正しい手順
1. 先生が **現在のmdファイル**（papers.md等）と**新しいJSONLファイル**の両方をアップロードする
2. JSONLのみアップロードされた場合、Claudeはmdを生成しない
3. ClaudeはJSONLと現在のmdを比較し、**差分（追加・変更分）のみ**を特定する
4. 差分を `papers_updates.md` 等の別ファイルとして出力する
5. 先生が内容を確認してから、手動で既存のmdに追記・修正する

### Claudeへの作業依頼時に必要なもの
- このマスタープロンプト
- 修正対象の現在の `.astro` ファイル（またはtakezawa-site.zip）
- 変更内容の説明

### フォントサイズ原則
- 本文・説明文・著者名・雑誌名等: 最低15px
- タイトル・見出し: 本文より必ず大きく（16px以上）
- 例外（小さくてよい）: ナビボタン・バッジ・ラベル・EN/JAトグル・DOI

### レイアウト原則
- ナビゲーション: 固定64px、1pxボーダー
- 影なし（box-shadow禁止）
- ボーダーは1px solid のみ
- 余白: padding 48px（モバイルは20px）
- レスポンシブブレークポイント: 900px / 680px

```typescript
import { load } from 'js-yaml';
import { readFileSync } from 'fs';
import { join } from 'path';

function parseFrontmatter(raw: string) {
  const match = raw.match(/^---\n([\s\S]*?)\n---/);
  if (!match) return {};
  return load(match[1]) as Record<string, any>;
}
```

## 5. Astro実装の重要ルール

### scriptタグ
- すべての`<script>`タグに`is:inline`属性が必須
- TypeScriptの型注釈をscriptタグ内に書いてはならない

### set:htmlのCSSスコープ問題
- `set:html`で動的生成した要素にはscopedなCSSが当たらない
- 必ず`:global()`を使う:
```css
:global(.theme-detail p) { font-size: 15px; }
```

### EN/JAトグル
```css
.pub-content-ja { display: none; }
.lang-ja .pub-content-en { display: none; }
.lang-ja .pub-content-ja { display: block; }
```

## 8. GitHub Actions設定

```yaml
name: Deploy to GitHub Pages
on:
  push:
    branches: [main]
permissions:
  contents: read
  pages: write
  id-token: write
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: npm
      - run: npm ci
      - run: npm run build
      - uses: actions/upload-pages-artifact@v3
        with:
          path: dist/
  deploy:
    needs: build
    runs-on: ubuntu-latest
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    steps:
      - id: deployment
        uses: actions/deploy-pages@v4
```

GitHub Settings → Pages → Source を GitHub Actions に設定。
デフォルトブランチは main（masterではない）。
